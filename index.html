GAS 코드 수정하기

구글 앱 스크립트(`Code.gs`) 편집기로 돌아가셔서 **`doGet(e)`** 함수를 아래와 같이 변경해 주세요!

function doGet(e) {
  var callback = e.parameter.callback;
  var data = {
    success: true,
    tasks: getMyClassroomTasks() // 과제 함수
  };
  
  var output = callback + '(' + JSON.stringify(data) + ')';
  return ContentService.createTextOutput(output)
    .setMimeType(ContentService.MimeType.JAVASCRIPT);
}
⚙️ 배포 설정 시 필수 3가지
  1. [배포] -> [새 배포] 클릭
  2. 다음 사용자 지정으로 실행: 나(Me)
  3. 액세스할 수 있는 사용자: 모든 사용자 (Anyone)
